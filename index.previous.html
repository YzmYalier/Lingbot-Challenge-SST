背景与实验设置

LingBot-VLA 2.0

LingBot-VLA 2.0 用 Qwen3-VL-4B 作 VLM 主干。三路相机图像分别经 ViT 编码成 64 个 token，和语言指令拼在一起，后面再接当前帧和未来帧两组可学习 query。整个 prefix 用 MRoPE 编码，内部是因果注意力。动作专家和 VLM 并行，同样是 36 层 Qwen2 结构，FFN 换成 1 个共享专家加 32 个 sigmoid 路由专家（top-4）的 MoE，流匹配时间步通过 AdaRMSNorm 注入。两条流在每一层拼接 QKV 做联合注意力。训练时两组 query 经 Resampler 分别回归冻结的 LingBot-Depth 深度特征和 DINO-Video 时序特征。推理时不用 teacher，prefix 计算一次后存进 KV cache，之后约 10 步 Euler 去噪只运行动作专家。

任务与评测协议

训练数据是 RoboTwin clean-50（RoboTwin_lerobot_v30），后来发现这个数据集有残缺，修复见 N5。评测覆盖全部 50 个任务，分 clean 和 randomized 两种场景，每个任务 50 或 100 个 episode，各表都注明了 episode 数。

训练配置

训练使用 16 或 32 张 H200，global batch size 固定为 1024，micro batch size 为 32，卡数不同时调整梯度累积次数。除学习率外（见 B3.1 和 N4），其余超参和 LingBot-VLA 2.0 默认配置相同。

基于 N0|改动 cam_high 换成 SAM 掩码图，训练和评测都做同样处理（62ef792、d1c21ee）|负责人 TODO

N2

Qwen-SAM 前景掩码 v2：VLM 复核

基于 N1|改动 放宽物体召回的 prompt，增加 Qwen 对每个 mask 的是非复核；训练数据和评测都换成 judged 版本（63c6b8a）|负责人 TODO

我们发现 Qwen 虽然不能直接输出 mask，但给定图像和 mask，它能可靠地判断 mask 是否对应目标物体。所以 v2 先放宽召回 prompt，多提一些候选物体，再把每个 mask 连同图像和一个是非问题（"这个位置是 XX 吗"）送回 Qwen 复核，删掉错误的 mask。这样召回率提高了，错误率也降低了。

支线（WIP）：Dual-stream 辅助块

基于 N3 的 teacher 设置|分支 feat/sam-dual-stream（f85066c）|负责人 TODO

N3 里的 student 从掩码图预测原图的特征，属于跨视图监督。Dual-stream 想改成同视图监督：把原始 cam_high 作为一个和 policy 隔离的辅助块追加在 prefix 后面，depth/video head 只读这个辅助块，policy 和动作专家都看不到它。推理时去掉辅助块，prefix 里也不再有 task token。

fp32 检查发现，只要辅助块存在，policy 行的输出就会整体偏移约 0.05，所以训练和推理之间有偏差。这个问题还没修复，因此没有做评测。

放在未来工作。

基于 N4（不含 wrist aug）|分支 fix/module-lr-wrist-aug-data-integrity（217b4da），训练时 wrist_augment: false|负责人 TODO

N4 的逐任务结果里，click 类任务的成功率特别低，所以我们回头检查了数据，发现两个问题。

1. padding 出来的 action 也参与了 loss

episode 末尾的 chunk 不足 50 步时，LeRobot 会重复最后一个 action 补齐，并生成 action_is_pad。但 LingBot-VLA（v1 和 v2）计算 loss 时没有使用这个标记，pad 部分也会被监督。全数据集有 22.3% 的样本含 pad，pad 位置占全部 action 位置的 11.2%。click_bell 中这个比例达到 31.8%。模型没有历史记忆，"即将按下"和"已经按下"在单帧上看起来几乎一样，大量"保持静止"的监督会让模型在按下前就停住。修复后 pad 位置不再计入 loss（mask_action_pad: true）。

2. LeRobot v3.0 数据集帧错位

RoboTwin 官方在 Hugging Face 上发布的 LeRobot v3.0 数据集里，部分 episode 的视频段比 parquet 短，末尾几帧会读到下一个 episode 的画面。v2.1 版本没有这个问题。我们用 v2.1 重建了帧对齐的 v3.0 数据（RoboTwin_lerobot_v30_framefixed），并在这份数据上重新生成了 judged SAM 掩码。

讨论

主线上进入的改动有一个共同点：模型结构不变，改的是模型看到的东西和训练方式。N1/N2 改变输入图像；N3 让 teacher 看到它熟悉的自然图像；N4 降低预训练模块的学习率；N5 修复监督信号。没有带来提升的支线大多在动模型结构：多加一路图像（B2.1、B3.2），或者多加一组 query（B2.2）。我们的理解是，在只有 clean 数据的后训练中，和预训练时的输入分布、注意力结构越一致，保留下来的泛化能力越多。TODO：展开

局限与未来工作

  • 每个配置只训练了一个 seed。重复评测的差异约 2pp，多数单步提升也在 2–3pp。
  • 最好的 step 是根据测试集结果选的，最终数字偏乐观。
  • N2 同时改了训练数据和评测管线；N5 的两项修复没有单独消融。
  • 评测时需要额外运行 27B Qwen 和 SAM3，推理成本高。
  • 只在仿真中验证过。
  • Dual-stream（B3.3）的训练/推理偏差尚未修复。
