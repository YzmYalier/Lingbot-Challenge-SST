整体介绍

本文记录老年上海观光团（SST, Shanghai Senior Tour）参加蚂蚁灵波首届具身大模型挑战赛总决赛的实践，包括模型调优、实验分析与赛后总结。

本文有三个目的：

  1. 记录参赛过程。比赛以 LingBot-VLA 2.0 6B 预训练权重为起点，在 RoboTwin demo_clean-50 数据集上进行 post-training 调优，并在 demo_clean 与 demo_randomized 配置下评测。本文记录我们在这一过程中的实验、结果与选择。
  2. 探讨 VLA SFT 中值得注意的问题。借这次调优，我们探索了多视角输入、MetaQuery 监督、学习率优化、padding action 等问题，总结其中值得注意的设计与训练选择。
  3. 提供一种通过视觉 prompt 连接 System 1 与 System 2 的方式。我们的整体方案使用 Qwen-SAM 为 LingBot-VLA 2.0 提供显式的视觉 prompt，将高层语义理解转化为动作模型可直接读取的前景提示，为 System 1 与 System 2 的结合提供一种实践思路。

实验结论

  1. 优先从输入侧接入新信息

    同样从原图基线出发，保留 causal attention 的 SAM 第四视角优于 MetaQuery 辅助监督，而直接用前景图替换主视角的效果更好。这些结果说明，在本组任务中，让模型在动作预测时直接读取前景信息，比仅通过掩码重建目标引导表征学习更容易转化为操作收益。为 VLA 增加任务相关信息时，应优先考虑它能否在推理中被策略直接利用。

  2. 增加输入时，优先保留 VLM 原生的注意力形式

    在第四视角实验中，三种位置编码在 causal 设置下仅相差约 1.3 个百分点；同一位置编码改用 pair attention 后，成功率却一致下降，降幅为 2.6–5.0 个百分点。新增 token 不只带来更多信息，也可能改变预训练模型已有的信息交互方式。因此，相比精细设计新内容的位置编码，先让其可见关系贴合 VLM 原生的 causal attention，更值得优先考虑。

  3. 按模块分配学习率，平衡能力保留与任务适应

    统一降低学习率没有带来收益；降低 ViT、visual merger 与 LLM 的学习率、冻结 token embedding，同时保留动作与对齐模块的更新幅度，则在 15k 和 25k 时都带来了约 2.2 个百分点的 Randomized 提升。Post-training 不需要让所有模块以同样的速度变化：预训练程度高、希望保留已有表征的模块应使用更低的学习率，必要时冻结；承担下游适应的模块则需要足够的更新空间。

  4. 排除 padding action，避免把补齐动作当作任务监督

    Padding 是为了统一动作块长度引入的人工补齐，并不代表真实的决策轨迹。对于 RoboTwin 中没有 memory / history 设计的 VLA，反复监督 episode 末尾的保持动作，可能让相似的当前观测同时对应“继续执行”与“保持不动”，加剧“任务执行中”与“任务已结束”之间的歧义。因此，padding action 应从 loss 及其归一化分母中排除，让模型只学习有效动作。

  5. 将感知模型的迁移能力转化为 VLA 的视觉指导

    现有 VLM 与视频分割模型的跨场景物体定位、前景提取能力，可以通过视觉 prompt 为 VLA 提供有效指导。我们的 Qwen-SAM pipeline 用 Qwen 理解指令并识别相关对象，再由 SAM 提取前景。在 RoboTwin 这种以场景外观变化为主的 clean-to-randomized 迁移中，引入 SAM multi 前景输入后，Randomized 成功率从 36.2% 提高到 47.8%；结合掩码复核与渲染调整后进一步达到 50.8%。这些实验表明，Qwen-SAM 在这一迁移设置下十分有效，也提供了通过视觉 prompt 连接 System 1 与 System 2 的一种具体实现。
